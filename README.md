A tiny Python program that writes a single emoji — heart hands 🫶 — to `/output/entry.txt`, the one most likely to make a stranger smile. Chosen over the default smileys: a heart offered by two hands reads warm at first glance, works for any stranger, and is not a hug, a kiss, or a romantic face.

## Run it

```sh
python3 main.py
```
